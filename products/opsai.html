DZLabs Products · OpsAI

Every morning: what is wrong, what changed, what got fixed.

OpsAI snapshots each environment every hour, runs deterministic checks, turns what it finds into plain-language findings and writes one morning briefing with Claude. The safe fixes take one tap.

⏱ Hourly collection

Read-only snapshots of vCenter, Proxmox VE, Nutanix, AWS and Google Cloud. Partial collections are tolerated; a failed section never resolves findings it did not read.

✅ 50+ deterministic checks

Host state, alarms, datastore days-to-full, old snapshots, missing and stale backups, certificates, HA/DRS, quorum, ZFS, Ceph, public exposure, idle and oversized VMs. Thresholds live in JSON, not in code.

📰 A briefing, not a dashboard

Once a day Claude writes one headline and three short lists: today, changed since the last briefing, and fixed. Checks decide, Claude writes the words.

How it works

Collect

Every hour OpsAI reads each environment with a read-only account or API token.

Check

Deterministic checks open, refresh and resolve findings on their own. No guessing.

Brief

Claude turns the findings into a morning briefing and explains any finding on request, with the exact commands.

Fix

Allowlisted fixes run after one tap, with live preconditions. The next collection verifies the result.

See it in action

🛡 Safe by design

No autopilot. Nothing runs without a write credential and an enabled action kind. Every stored credential is sealed.

🔁 Findings that manage themselves

Findings open, refresh and resolve on their own. Snooze for 7 days or dismiss; a dismissed finding returns only after it resolved once.

📦 One binary, one file

A single static Go binary with the web client embedded and one SQLite file. Runs on your own host, phone-first UI.
